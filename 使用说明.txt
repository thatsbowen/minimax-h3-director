MiniMax H3导演台 · 使用说明
==========================

【重要：关于“未签名”提示】
本程序由个人开发者独立开发与发布，未购买商业代码签名证书，程序文件与分发包均无数字签名。
因此首次运行时，Windows 可能弹出“Windows 已保护你的电脑”或“未知发布者”提示。
处理方式：点击“更多信息” → “仍要运行”即可。
该提示是系统对所有无签名程序的统一拦截策略，不代表程序存在风险，不影响任何功能的正常使用。

【一、开始使用】
1. 解压整个 ZIP 到任意可写文件夹。
2. 双击「MiniMax H3导演台.exe」。
3. 首次启动会引导填写 MiniMax API Key：
   - 没有账号：点击「注册账号」
   - 需要余额：点击「充值余额」
   - 创建 Key：点击「创建 Key」，复制以 sk- 开头的长字符串
4. 粘贴 Key 后先点「测试连接」，通过后点「保存并进入」。
   也可以选择「先随便看看，稍后配置」，之后在左侧「设置」中补填。

【二、API Key 安全】
- Key 只保存在本机，使用 Windows 凭据加密（DPAPI）。
- 不会上传到任何第三方服务器，也不会写入日志。
- 共用电脑可在「设置」中选择「仅保存在内存」，退出应用后自动清除。

【三、快速创作】
1. 在「创作台」写下你想看的画面，例如：
   “雨夜的旧车站，穿米色风衣的女人拖着行李箱走向站台。”
2. 不知道怎么写，可点「灵感模式」套用模板，或点「导演模式」让 AI 帮你组织镜头、光线与声音。
3. 选择模型、分辨率、画幅和时长。
4. 需要时上传参考图片、首尾帧或参考视频。
5. 点「开始生成」。任务会在后台运行，完成后托盘中会收到通知。

【四、成片在哪里】
- 默认自动归档到程序目录下的 data\downloads\。
- 「作品库」中可预览、导出、复用参数或删除。
- 在「设置」中可打开数据目录和成片目录。

【五、数据备份与更新】
- 所有历史、素材、Key 都在 exe 同目录的 data\ 文件夹。
- 更新版本：先关闭应用，解压新 ZIP 覆盖程序文件，保留 data\ 文件夹。
- 建议定期把 data\ 文件夹复制到其他位置备份。

【六、计费说明】
- 生成费用由 MiniMax 按秒从你的账户余额扣除，本应用不代收任何费用。
- 界面中的预估费用仅供参考，最终以 MiniMax 官方账单为准。
- 赞赏页完全自愿，不接入支付，不影响任何功能。

【七、常见问题】
Q：启动后提示未配置 API Key？
A：到「设置」中填写并保存即可。

Q：测试连接失败？
A：检查网络、Key 是否复制完整、账户是否有余额；中国站 Key 对应 api.minimax.cn，国际站对应 api.minimax.io。

Q：视频链接过期 / 视频加载失败？
A：在作品详情中点击「重新获取视频」。只要 MiniMax 端任务仍在有效期内，就会重新下载并归档到本地。

Q：Windows 提示“未知发布者”？
A：应用未做代码签名，点击“更多信息 → 仍要运行”即可。

Q：程序目录不能写入？
A：应用会自动改用用户目录保存数据，实际路径可在「设置 → 本地数据」中查看。

【八、隐私】
无登录、无云端同步、无行为统计。除调用 MiniMax API 生成视频外，客户端不向任何服务器上传数据。
